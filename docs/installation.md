# 安装示意图与技术说明

本文档配合 [bom.md](./bom.md) 使用，给出通道、光电、走线、防水盒、手持器的安装细节和示意图。

所有尺寸单位为 mm，除非另注。

## 1. 通道总体俯视图

```
                    集羊圈
   ┌──────────────────────────────────────────┐
   │                                          │
   │            （现有集羊圈）                 │
   │                                          │
   └───────────────┬──────────────────────────┘
                   │ 漏斗口（收口）
        ┌──────────┴──────────┐
        │  ←收口约 1.7-1.9 m→ │
        └─┬───┬───┬───┬───┬──┘
          │道1 │道2 │道3 │道4│
          │窄  │窄  │窄  │宽 │
          │38  │38  │38  │45 │  ← 内净宽 mm
          │    │    │    │   │
          │2.0-2.5 m 长      │
          │                  │
          ▼ 出口             ▼
        ┌────────────────────┐
        │   门口主机箱        │
        │   (防水盒 200×150)  │
        │   贴在出口侧立柱    │
        └────────────────────┘

   图例：
   道1-3 = 母羊道（内净宽 36-38 cm）
   道4   = 公羊道（内净宽 42-45 cm，靠边，刷对比色）
   单道长 = 2.0-2.5 m（传感区里基本只有一只羊躯干）
   侧板高 = 90-100 cm（封实，羊看不见邻道）
```

### 关键尺寸

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 通道数 | 4 道（3 窄 1 宽） | 母羔走窄道，宽道给大公羊 |
| 单道内净宽 | 窄 36–38 cm，宽 42–45 cm | 比羊肩宽略宽，防止侧身并排过 |
| 单道长度 | 2.0–2.5 m | 保证传感区里只有一只羊 |
| 侧板高度 | 90–100 cm | 挡视线防回头，高于羊背 |
| 漏斗夹角 | 不宜太陡 | 从集羊圈口收到 4 道，避免洞口对撞 |

## 2. 单道光电布置（俯视 + 侧视）

### 2.1 俯视图

```
   封板 ────────────────────────────── 封板
    │                                   │
    │   [TX-A] ─────→ [RX-A]            │  ← 光束 A（入口侧）
    │    │                 │            │
    │    │    40-50 cm     │            │  ← 两束间距
    │    │                 │            │
    │   [TX-B] ─────→ [RX-B]            │  ← 光束 B（出口侧）
    │    │                 │            │
    │                                   │
   漏斗口                              出口
   ←羊走方向→

   每道 = 2 对光电 = 2 TX + 2 RX = 4 只 M18 管
   4 道共 8 对 = 16 只（BOM 买 10 套 = 20 只，含 2 套备用）

   判定逻辑：
   - A 先挡、B 后挡 + 两束有重叠 = 1 只羊出门
   - B 先挡、A 后挡 = 回圈
   - 只挡 A 不挡 B = 探头又退，不计
   - 计数后闭锁 250-400 ms 防蹄子二次沿
```

### 2.2 侧视图（光电高度）

```
            方管立柱 40×40
              ┌─┐
              │ │  ← 侧封板高 90-100 cm
              │ │
   ───────────┤ ├───────────  封板顶
              │ │
              │ │
   ...........│ │...........  ← 地面
              │ │
              └─┘

   光电开孔高度 = 55-65 cm（对准羊躯干中线）
   现场用一只中等羊站通道里，看躯干中线在哪儿，按那个高度开孔

   ⚠ 不要对准腿！四条腿会被数成多只羊
   ⚠ 不要对准背！背太高小羊漏过
   ⚠ 对准躯干中线最稳
```

### 2.3 光电固定剖面图（发射侧 / 接收侧对称）

```
   发射侧（TX）                    接收侧（RX）

    方管 40×40                      方管 40×40
    ┌────┐                          ┌────┐
    │    │                          │    │
    │    │ L型支架                   │    │ L型支架
    │    │←──焊───┐                 │    │←──焊───┐
    │    │        │                 │    │        │
    │    └────────┤ 封板            │    └────────┤ 封板
    │             │ 1.0mm           │             │ 1.0mm
    │   [TX]──────┤─────────→  ───→ ┤──────[RX]   │
    │   M18管     │  光束           │      M18管  │
    │   螺母夹紧  │                 │   螺母夹紧  │
    │   ○○       │                 │   ○○       │
    │             │                 │             │
    └─────────────┘                 └─────────────┘
          ↑                               ↑
       走线孔                          走线孔
       Φ10 mm                          Φ10 mm
       线穿入方管                       线穿入方管

   固定步骤：
   1. 封板开 Φ18.5 mm 孔（开孔器/台阶钻头）
   2. L 型支架一端焊在方管立柱上，另一端贴住封板孔
   3. 光电从孔穿过，前后各一只 M18 螺母夹紧
   4. 松螺母微调角度对光轴，对准后拧紧
   5. 前端套遮光罩（PVC 短管）防尘
```

### 3.2 走线方式对比

| 方式 | 防护等级 | 施工难度 | 推荐场景 |
| --- | --- | --- | --- |
| 方管内穿线 | 最高 | 难（需铁丝牵引） | 首选，完全防雨防啃 |
| 方管背面 + PVC 线槽 25×16 | 够用 | 中 | 不穿管时的备选 |
| 裸线 + 扎带 | 差 | 易 | 仅临时测试 |

### 3.3 线缆规格

| 段落 | 线缆 | 芯数用途 |
| --- | --- | --- |
| 光电 → 方管内 | 光电自带 2m PVC 线 | TX 两芯，RX 三芯 |
| 方管内延长 | RVV 3×0.5 | 光电延长（TX 用 2 芯，余 1 芯备用） |
| 端部防水盒 → 主机箱 | RVV 10×0.5 | 8 路信号 + 12V + GND |
| 220V → 主机箱 | RVV 2×0.75 | 火线 + 零线 |
| 主机箱 → 插排 | 国标三芯 1.0 | 火线 + 零线 + 地线 |

### 3.4 接收侧信号汇流（端部防水盒内）

```
   端部防水盒内（单道，2 个接收器）：

   RX-A 棕+ ──┬── 12V（并联）
   RX-B 棕+ ──┘
   RX-A 蓝- ──┬── GND（并联）
   RX-B 蓝- ──┘
   RX-A 黑信号 ──→ 单独一根线 → 主机箱光耦板 CH1
   RX-B 黑信号 ──→ 单独一根线 → 主机箱光耦板 CH2

   ⚠ 信号线不要并联！每路信号单独一根线进光耦板
   ⚠ 4 道共 8 路信号 + 12V + GND = 10 芯，用 RVV 10×0.5
```

```
   ESP32-C3 GPIO 引脚分配（示例，固件可改）：

   GPIO0  ── 出门（蓝）
   GPIO1  ── 回圈（绿）

   GPIO4  ── +1（黄）
   GPIO5  ── -1（黑）

   I2C 引脚：
   GPIO8  ── SDA（OLED）
```

## 6. 防水防土措施

### 6.1 光电接头防水

```
   光电 2m 线 ──┐
                ├── 焊接接头 ── RVV 延长线
               ─┤
                │
   ┌────────────┴────────────┐
   │ 1. 焊好接头              │
   │ 2. 套带胶热缩管（内壁有胶）│
   │ 3. 加热缩紧，胶溢出=密封  │
   │ 4. 再缠一层防水胶带       │
   └─────────────────────────┘

   ⚠ 接头不要留在通道里！收进方管内或端部防水盒
   ⚠ 带胶热缩管 ≠ 普通热缩管，必须买带胶的
```

```
   │                             │
```

## 7. 接线端子定义速查

## 8. 安装顺序

### 8.1 桌面验证阶段（第一批到货后）

1. 把 ESP32-S3、光耦板、TM1637、OLED 插在 **面包板 MB-102** 上
2. 用杜邦线连接，2 套光电用纸箱模拟羊推过
3. 烧固件，验证 A→B 判定逻辑、闭锁时间、数码管显示
4. 调到误计/漏计可接受，再买齐 8 对

### 8.2 现场安装阶段（第二批到货后）

1. **焊工做通道**：按图焊方管骨架、封板、开 Φ18.5 光电孔、开 Φ10 穿线孔、焊遮檐
2. **装光电**：L 型支架 + M18 螺母固定，对光轴
3. **穿线**：光电线穿入方管，走到端部防水盒
4. **端部汇流**：防水盒内用 WAGO 并联 12V/GND，信号单独引出
5. **多芯电缆**：RVV 10×0.5 穿 PVC 管，从端部盒到门口主机箱
6. **装门口箱**：固定防水盒，装 LRS-35-12、Mini560、光耦板、ESP32、TM1637、指示灯
7. **接线**：按 7.1–7.3 接线表连接
8. **防水处理**：PG9 拧紧、穿线孔打胶、遮檐装好
9. **先装 1 道试半天**：真羊过 20–30 只，标定高度和闭锁时间
10. **装齐 4 道**：确认无误后装齐

### 8.3 手持器组装

1. 手持壳开孔：OLED 窗、6 个按键孔、充电口、挂绳孔
2. 6 个轻触开关焊在洞洞板上
3. IP5306 焊好电池线（BAT+/BAT-）和输出线（OUT+/OUT-）
4. 18650 电池盒引线焊到 IP5306 BAT+/BAT-
5. IP5306 输出 5V 接 ESP32-C3 5V/GND
6. ESP32-C3 GPIO 用杜邦线接洞洞板上 6 个开关
7. ESP32-C3 I2C 接 OLED 4 针
8. 全部塞入手持壳，用双面胶/热熔胶固定
9. 装挂绳

## 9. 检查清单

### 9.1 安装前检查

- [ ] 光电型号：E3F-5DN1 + E3F-5L（不是漫反射 DS30C4）
- [ ] 光电输出：NPN 常开（不是 PNP、不是常闭）
- [ ] 光耦板方向：PLC 输入型（12V 进、3.3V 出）
- [ ] OLED：I2C 4 针 SSD1306（不是 SPI 7 针）
- [ ] 门口 MCU：ESP32-S3 N16R8（不是 U.FL 版）
- [ ] 手持 MCU：ESP32-C3 SuperMini
- [ ] Mini560：固定 5V（不是可调 Mini360）
- [ ] 18650：带保护板

### 9.2 安装后检查

- [ ] 光电对光轴：松螺母调角度，接收器指示灯亮=对准
- [ ] 光电高度：对准羊躯干中线（55–65 cm）
- [ ] 所有接头套带胶热缩管
- [ ] 方管穿线孔打硅酮胶
- [ ] 门口箱遮檐装好
- [ ] PG9 进线朝下
- [ ] 光耦板输出侧 VCC = 3.3V
- [ ] 12V/GND 共地（LRS-35-12 的 V- = ESP32 GND = 光耦板 GND）
- [ ] 端子台螺丝拧紧，无松动
- [ ] 箱内干燥剂放好

### 9.3 通电测试

- [ ] 220V 接通 → LRS-35-12 输出 12V（万用表量）
- [ ] Mini560 输出 5V（万用表量，不能超 5.25V）
- [ ] ESP32-S3 启动，TM1637 数码管亮
- [ ] 挡光电 → 数码管 +1
- [ ] AD16-22DS 指示灯亮
- [ ] 手持器开机，OLED 显示
- [ ] 手持器按键 → 门口同步
- [ ] ESP-NOW 通信距离测试（手持在门口 10m 内）
